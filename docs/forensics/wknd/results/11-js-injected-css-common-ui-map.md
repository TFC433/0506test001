## Executive Conclusion

The active dashboard frontend has multiple common UI ownership layers: static CSS from `public/dashboard.html:10`, `public/dashboard.html:11`, runtime script loading from `public/dashboard.html:430` through `public/scripts/import-bundle.js:15` to `public/scripts/import-bundle.js:20`, and JavaScript-injected CSS from common helper files.

EVIDENCED: the focused common helper files inject CSS for toasts, pagination, notification animation, and temporary theme transitions. Evidence: `public/scripts/services/ui.js:22` to `public/scripts/services/ui.js:27`, `public/scripts/core/utils.js:175` to `public/scripts/core/utils.js:190`, `public/scripts/core/utils.js:194` to `public/scripts/core/utils.js:209`, `public/scripts/core/theme-toggle.js:365` to `public/scripts/core/theme-toggle.js:383`.

EVIDENCED: adjacent company UI modules also inject local styles, including toast container rules that overlap with the shared toast system. Evidence: `public/scripts/companies/company-list.js:22` to `public/scripts/companies/company-list.js:83`, `public/scripts/companies/company-details-ui.js:17` to `public/scripts/companies/company-details-ui.js:105`.

UNKNOWN: this run did not execute the app in a browser, so final runtime cascade order after dynamic route/page rendering is not proven. Static evidence shows load order and injection points, but live DOM timing remains a runtime question.
